### 🚀 About Me

I'm a **mechatronics engineer** specializing in embedded systems, with a growing focus on control and robotics. I design intelligent systems using various microcontrollers — and I'm also enthusiastic about expanding into application programming, machine learning, and deep learning.

I believe the most exciting systems lie at the intersection of **hardware and intelligence**. I'm currently bridging that gap by exploring how ML and DL models can run on edge devices.

- 🔭 Currently exploring **ML/DL on embedded & edge devices**
- 🤖 Interested in **robotics, control systems, and IoT**
- 🧠 Also diving into **prompt engineering**
- 🛠️ Love tinkering with hardware and running experiments
- 📍 Based in Sidoarjo, East Java, Indonesia
